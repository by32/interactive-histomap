# soldiers.glb

Built by `npm run build:models` (`scripts/blender/models.py`).

Every figure's anatomy is **Blender Studio's realistic male base mesh**
(`GEO-body_male_realistic`) from the *Human Base Meshes* asset bundle v1.4.1,
by Blender Studio and community contributors, released under
**CC0 1.0 (public domain dedication)**:

- page: https://www.blender.org/download/demo/asset-bundles/
- file: https://mirror.blender.org/demo/asset-bundles/human-base-meshes/human-base-meshes-bundle-v1.4.1.zip
- SHA-256 of the zip: `811f43accbb31a88266d932f8f5563b2d13586fca0ba2693aad1f5fe582b3515`

The body is posed, decimated, dressed and armed by the scripts in
`scripts/blender/`; clothing, armour, shields and weapons are modelled there.
